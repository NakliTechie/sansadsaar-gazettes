S.O. 460 ( E ) .— In Exercise of Power conferred by clause 37A of Section 2 of the Railway ( Amendment ) Act 
2008 , General Manager / East Central Railway has approved to declare " Surface Triangle between Bhadaura Station 
( PATNA - DDU Main line ) and New Crossing Station Karma ( Dildarnagar - Tarighatline ) ( 11.10KM ) " as Special 
Railway Project . Therefore , " Surface Triangle between Bhadaura Station ( PATNA - DDU Main line ) and New 
Crossing Station Karma ( Dildarnagar - Tarighatline ) ( 11.10KM ) " Project is declared Special Railway Project in the 
State of Uttar Pradesh .
